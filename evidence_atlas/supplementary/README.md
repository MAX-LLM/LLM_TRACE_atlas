# Supplementary atlas exports

- `entity_counts.csv`: report counts for every canonical graph entity.
- `entity_dictionary.csv`: source fields and deterministic compilation rules for each entity type.
- `audit_candidates.csv`: deterministic consistency checks for targeted full-text review; flags are not confirmed errors.
- `knowledge_graph_caption.txt`: draft caption for the interactive graph or a supplementary figure.
- `methods_text.txt`: draft supplementary methods description.

The two primary profile labels use titles and abstracts with targeted full-text corrections; descriptive fields, including trial evidence, use titles and abstracts. Full texts should be consulted before clinical or policy inference.
